## About

This repository contains the practical assignments and experiments completed as part of the Artificial Intelligence Lab.

The programs are implemented using Java and cover AI problem-solving techniques, search algorithms, data preprocessing, knowledge representation, machine learning, and neural networks.

## Labs

| **Lab** | **Topics** |
| ------- | ---------- |
| Lab 1   | AI Environment Setup, Production Systems, Water Jug Problem |
| Lab 2   | BFS, DFS, Hill Climbing, Best First Search, A* |
| Lab 3   | Data Preprocessing, EDA, NumPy, Pandas, Visualization |
| Lab 4   | Knowledge Representation, Rule Systems, Semantic Networks |
| Lab 5   | Decision Tree Classifier and Evaluation |
| Lab 6   | PyTorch, Linear Regression, Neural Networks |
| Lab 7   | Explainable AI, Adversarial Examples, PCA/SVD, Mini-Project |

## Requirements

- Java Development Kit (JDK)
- Any Java IDE (IntelliJ IDEA, Eclipse, or VS Code)
- Git (for version control)

## Execution

Compile and run Java programs using:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the name of the Java class containing the main method.
